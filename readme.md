# Campeonato Gamer

## Situação Problema 

Nossa turma vai organizar partidas de jogos. Queremos registrar **Jogo**, **time A**,  **time B**,  **placar** e  **status**. Uma partida começa `agenda` com placar `0 X 0`. Depois podemos atualizar o resultado para `finalizar`.

Ao final, a API terá estas rotas

| Método  | Rota    |   O que faz   | 
| ---     | ---     |   ---
| GET     | `/partidas`     |   Confirma que a API está funcionando|
| GET     | `/partidas`      |  Lista e filtra partidas|
| GET        | `/partidas`       | Buscar uma partida|
| POST        | `/partidas`       | Alterar uma partida e o placar|
| PUT       | `/partidas`       | Excluir uma partida|
| DELETE        | `/partidas`       |
